## 한 줄 정의

IP 주소 범위를 **한 덩어리(서브넷)로 묶고**, `/24` 처럼 짧게 적는 표기법.

## 비유

아파트 주소에서 **동까지는 같고 호수만 다른** 집들의 묶음. `192.168.10.0/24` 는 "앞 24비트(192.168.10)까지가 우리 동, 마지막 한 자리가 호수" 라는 뜻이다.

## 예시

```bash
# 연구실 VM 대역 192.168.10.0/24 → 192.168.10.1 ~ 192.168.10.254 (254대)
ip route                    # 내 서브넷과 게이트웨이 확인
ipcalc 192.168.10.0/24      # 범위·호스트 수 계산 (apt install ipcalc)
```

Proxmox 에서 VM 에 고정 IP 를 줄 때 `192.168.10.20/24` 처럼 주소 뒤에 서브넷을 꼭 붙인다. 숫자가 작을수록(`/16`) 범위가 넓고, 클수록(`/32` 는 단 1개) 좁다. 방화벽에서 "Tailscale 대역(`100.64.0.0/10`)만 허용" 처럼 범위를 한 줄로 적을 때도 이 표기를 쓴다.

## 헷갈리기 쉬운 것

- **서브넷 마스크** `255.255.255.0` 과 `/24` 는 같은 뜻의 두 표기. 앞에서부터 1이 24개 켜져 있다는 말이다.
- **사설 IP** 대역(`10.x`, `192.168.x`)은 "어떤 주소를 내부용으로 쓰기로 약속했나"의 문제고, 서브넷은 "그 주소를 어떻게 자르나"의 문제.
