## 한 줄 정의

리눅스 명령어와 **시스템 관리 능력**을 검증하는 국가공인 민간 자격증.

## 비유

요리사 자격증. 칼질(명령어)과 주방 관리(계정·권한·서비스)를 아는지 시험지로 확인하지만, 실제 주방에 서 본 사람을 이기진 못한다.

## 예시

| 등급 | 형식 | 범위 | 비고 |
| --- | --- | --- | --- |
| 2급 | 1차 온라인 필기 → 2차 필기 | 리눅스 일반(파일·권한·프로세스·셸), 시스템 관리, 네트워크·서비스 | 입문, 전공자면 2~3주 [확인 필요] |
| 1급 | 필기 + 실기(실제 리눅스 환경 작업) | 서버 설치·서비스 구성·보안·장애 대응 | 인프라 직무 지원자용 [확인 필요] |
| 공통 | 주관 한국정보통신인력개발센터(KAIT), 연 2회 | | [확인 필요] |

시험 범위의 8할은 홈랩에서 이미 하고 있는 일이다. Proxmox 에 Ubuntu VM 하나 만들고 다음을 손으로 해 보면 2급 범위를 거의 다 지난다.

```bash
useradd -m -G docker eclab                 # 계정·그룹
chmod 640 .env && chown eclab:eclab .env   # 권한 8진수 읽기
systemctl status caddy && journalctl -u caddy -n 50   # 서비스·로그
ss -tlnp | grep 8080                       # 이 포트 누가 쓰나
crontab -e        # 0 3 * * * /opt/backup.sh  → 크론 표현식
df -h; du -sh /var/lib/docker              # 디스크 어디가 찼나
```

자격증 공부는 "왜 이 명령이 있는지" 를 체계로 묶어 주고, 홈랩은 "실제로 터졌을 때 뭘 치는지" 를 몸에 남긴다. **인프라·시스템·네트워크 직무나 공기업 IT 직렬 가산점 항목**에 종종 들어가고 [확인 필요], 개발 직무 지원자에게는 우선순위가 낮다. 면접에서는 자격증보다 "서버 디스크가 꽉 찼을 때 어떻게 찾아서 정리했나요?" 같은 경험 질문으로 같은 내용을 확인한다.

## 헷갈리기 쉬운 것

- **LPIC·RHCSA**는 국제 자격. RHCSA 는 실기 100% 라 외국계·대형 인프라 조직에서 리눅스마스터보다 통한다 [확인 필요]. 국내 신입은 리눅스마스터 2급 + 홈랩 경험이 가성비.
- **네트워크관리사**는 장비·케이블링·라우팅 쪽 자격. 리눅스마스터는 서버 OS 안쪽이다.
- **1급 vs 2급**: 2급은 명령어를 아는지, 1급은 서버를 세우고 지킬 수 있는지. 인프라 갈 게 아니면 2급까지만.
