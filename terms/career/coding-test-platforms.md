## 한 줄 정의

코테 연습용 **온라인 문제 풀이 사이트** 세 곳으로, 각각 쓰임새가 다르다.

## 비유

헬스장 세 군데. 백준은 기구가 제일 많은 대형 헬스장, 프로그래머스는 국내 시험장과 같은 기구를 갖춘 곳, LeetCode 는 해외 대회 규격 헬스장이다.

## 예시

```text
백준(BOJ) + solved.ac
  - 문제 3만 개 이상, 한국어. 입력을 표준 입력에서 직접 읽는 방식(sys.stdin)
  - solved.ac 티어: 브론즈 → 실버 → 골드 → 플래티넘 → 다이아 → 루비 (각 5~1단계)
  - "단계별로 풀어보기", 유형별 문제집, 삼성 SW 역량 테스트 기출 문제집
프로그래머스
  - 함수 solution() 을 채우는 방식. 국내 기업 코테 상당수가 이 환경 [확인 필요]
  - Lv.0~5, "코딩테스트 고득점 Kit" 이 유형별 정리 — 시험 3~4주 전 필수
  - 카카오 기출 공개 문제로 국내 상위 난도 감 잡기
LeetCode
  - 영어, Easy/Medium/Hard. 외국계·빅테크 면접 빈출 (Blind 75, NeetCode 150 목록)
  - 문제 아래 Discussion 에서 다른 사람 풀이와 복잡도 비교 가능
```

쓰는 순서는 이렇다. 백준 "단계별로 풀어보기" 로 입출력과 기본 자료구조를 잡고, 유형별 문제집으로 실버 상위~골드 중반까지 훈련한 뒤, 시험 3~4주 전에 프로그래머스 Lv.2~3 로 환경(함수형 입력, 채점 방식)에 적응한다. 외국계나 영어 면접이 있는 곳을 볼 거면 그때 LeetCode Medium 을 추가한다. 목표 티어는 흔히 **골드**를 기준선으로 말한다 — 골드 문제를 스스로 풀면 국내 대부분 코테 통과권이라는 게 통설이지만 기업마다 다르다 [확인 필요]. 티어 숫자보다 "골드 문제를 1시간 안에, 남의 풀이 없이" 가 진짜 기준이고, 이력서에 solved.ac 프로필 링크를 넣는 사람도 있으니 계정 하나로 꾸준히 쌓는다.

## 헷갈리기 쉬운 것

- **solved.ac** 는 백준 문제에 난이도 티어를 붙이는 별도 사이트. 백준 계정과 연동해 쓴다.
- **Codeforces·AtCoder** 는 실시간 대회 사이트. 취업 코테엔 과하지만 실력을 한 단계 올리고 싶을 때 쓴다.
- **프로그래머스 Lv 와 solved.ac 티어**는 서로 환산되지 않는다. 대략 Lv.2 ≈ 실버 상위~골드 하위라는 말이 있지만 편차가 크다 [확인 필요].
