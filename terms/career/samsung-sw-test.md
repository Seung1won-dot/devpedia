## 한 줄 정의

삼성 계열 SW 직군 지원 시 보는 **구현·시뮬레이션 위주 코딩 시험**.

## 비유

일반 운전면허(보통 코테)와 별개로 봐야 하는 **대형 면허 시험**. 코스가 정해져 있어서 그 코스를 반복 연습한 사람이 붙는다.

## 예시

```text
형식    오프라인 고사장 응시, 3시간 2문제 [확인 필요]
언어    C/C++·Java·Python 등에서 선택, 세부 허용 목록은 공고 확인 [확인 필요]
환경    지정 IDE, 인터넷·외부 자료 불가, 표준 입출력 [확인 필요]
등급    A/B/C 형으로 나뉘며, 신입 채용 코테는 A 형 수준·B/C 는 재직자 인증이라고 알려짐 [확인 필요]
출제    격자판 시뮬레이션(로봇·주사위·상어), 구현, BFS/DFS, 백트래킹, 조합 완전탐색
합격    2문제 다 맞아야 안전하다는 말이 많다 [확인 필요]
```

준비는 백준 "삼성 SW 역량 테스트 기출 문제" 문제집이 사실상 교과서다. 로봇 청소기(14503), 주사위 굴리기(14499), 아기 상어(16236), 치킨 배달(15686), 미세먼지 안녕!(17144) 같은 문제가 전형이다.

```text
8~12주 준비 순서
1. 구현 기본기 — 2차원 배열, 방향 배열 dx/dy, 90도 회전, 경계 검사가 손에 붙을 때까지
2. BFS/DFS + 백트래킹 — 격자 최단거리, 연결 요소, n개 중 k개 고르기(재귀로 직접)
3. 기출 2회독 — 1회차는 시간 무제한으로 풀고, 2회차는 안 보고 60분 안에 다시
4. 시뮬레이션은 문제를 "규칙 목록" 으로 옮겨 적고, 한 규칙 = 한 함수로 쪼갠다
```

이 시험의 특징은 알고리즘 지식보다 **긴 조건을 하나도 빠뜨리지 않고 코드로 옮기는 끈기**다. DP·그래프 이론은 거의 안 나오고, 문제 설명이 두 쪽을 넘는 대신 규칙을 잘못 읽으면 예제부터 틀린다. 시간 배분은 한 문제 60~80분, 남는 시간엔 예외 케이스(경계에 붙은 물체, 크기 1 격자)를 직접 만들어 넣어 본다. 디버깅은 격자를 print 로 찍어 한 턴씩 눈으로 따라가는 게 제일 빠르다. 삼성 계열사(전자·SDS 등) SW 직군 공채가 이 시험을 공통으로 쓴다고 알려져 있으니 [확인 필요], 지원 전에 각 계열사 공고를 따로 확인한다.

## 헷갈리기 쉬운 것

- **일반 기업 코테**는 온라인·유형 다양(DP·이분탐색 포함)·4~5문제 중 몇 개. 삼성은 오프라인·구현 위주·2문제 전부.
- **GSAT(삼성직무적성검사)** 는 수리·추리 인적성 시험. SW 직군은 SW 역량테스트가 이를 대신한다고 알려져 있다 [확인 필요].
- **SW Expert Academy(SWEA)** 는 삼성이 운영하는 문제 사이트. 모의 SW 역량테스트 문제가 있어 시험 형식에 익숙해지기 좋다.
