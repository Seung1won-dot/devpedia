## 한 줄 정의

졸업 전 4년을 **언제 무엇을 쌓을지** 학년 단위로 나눈 취업 준비 순서표.

## 비유

농사 달력. 가을에 거두려면 봄에 뿌려야 하는 것이 정해져 있듯, 4학년에 지원하려면 1~2학년에 시작해야 하는 것이 있다.

## 예시

| 학년 | 핵심 | 구체 행동 | 학년 말 결과물 |
| --- | --- | --- | --- |
| 1~2학년 | 언어 하나 확실히 + 기본기 | Python 또는 Java 하나로 자료구조·알고리즘 수업 따라가기, 모든 과제를 Git 으로 관리(작은 커밋 습관), 백준 브론즈 → 실버 | GitHub 1년치 커밋, 백준 100~150문제 |
| 3학년 | CS 집중 + 직무 결정 + 팀 프로젝트 | OS·네트워크·DB 를 듣는 학기에 면접 질문 형태로 정리, 희망 직무(백엔드·프론트·인프라·데이터·AI) 하나 결정, 팀 프로젝트 1~2개를 배포까지, 여름·겨울 인턴 지원, 정처기 필기 | 배포된 프로젝트 1개, 트러블슈팅 기록 5건, 인턴 지원 경험 |
| 4학년 | 실전 | 코테 골드 목표, CS 질문 100개 정리 + 모의 면접, 포트폴리오·이력서 완성, 어학 마감, 상반기 수시 → 하반기 공채 | 이력서 v3, 포트폴리오 사이트, 지원 20곳 |

순서가 핵심이다. 4학년에 언어부터 시작하면 코테·프로젝트·CS 정리가 한 학기에 몰려 어느 것도 안 된다. 3학년의 인턴 지원은 떨어져도 된다 — 서류·코테·면접 경험이 남고, 4학년 지원서에 "지원해 봤다" 가 아니라 "어디까지 갔다" 를 쓸 수 있다. 학부연구생도 3학년 경로 중 하나다. 연구실에서 실제 서버·데이터·GPU 를 만지는 일은 프로젝트 1개 + 트러블슈팅 기록 여러 건으로 환산된다.

4학년 1년은 이렇게 흘러간다 [확인 필요].

```text
1~2월   코테 집중 (하루 2~3문제, 골드 진입)
3~5월   상반기 수시 채용 — IT 서비스 기업·스타트업 위주, 코테 → 면접
6~8월   인턴 또는 포트폴리오·이력서 정리, CS 질문 정리 마무리
9~11월  하반기 공채 — 대기업(삼성·LG·현대 등)·공기업, 자격증·어학 요건 확인
```

늦게 시작했다면(4학년 1학기 시작) 압축한다. 코테 3개월 → 프로젝트 하나를 배포까지 마무리 2개월 → CS 정리는 병행. 자격증·어학은 목표 공고가 요구할 때만.

## 헷갈리기 쉬운 것

- **roadmap.sh 같은 기술 로드맵**은 "무엇을 배울지" 지도, 이 카드는 "언제" 순서. 둘을 겹쳐 봐야 한다.
- **학점**: 프로젝트·코테가 없는 4.3 보다 프로젝트가 있는 3.5 가 IT 기업에선 유리한 경우가 많고, 공기업은 학점·자격증·어학 비중이 크다 [확인 필요].
- **스펙 나열 vs 직무 일관성**: 자격증 5개보다 한 직무로 이어지는 프로젝트 2개가 서류에서 강하다.
