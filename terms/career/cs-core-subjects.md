## 한 줄 정의

자료구조·알고리즘·OS·네트워크·DB·컴퓨터구조, **어떤 직무든 공통으로 묻는** 전공 기초.

## 비유

의사 국가고시의 기초의학. 어느 과를 가든 해부·생리는 다 묻는 것처럼, 프론트든 AI 든 이 여섯은 다 묻는다.

## 예시

과목마다 "이건 반드시 나온다" 는 질문이 있고, 이 사전에서 시작할 카드가 있다.

| 과목 | 최빈출 질문 | 시작 카드 |
| --- | --- | --- |
| 자료구조 | 배열과 연결 리스트의 차이는? / 해시 충돌은 어떻게 처리하나? | array, hash-table |
| 알고리즘 | 이 코드의 시간복잡도는? / 퀵 정렬과 머지 정렬 비교 | big-o, sorting |
| 운영체제 | 프로세스와 스레드의 차이는? / 데드락 발생 조건 4가지 | multiprocess-multithread, deadlock |
| 네트워크 | TCP 와 UDP 의 차이는? / 주소창에 URL 을 치면 일어나는 일 | tcp-udp, url-to-render |
| 데이터베이스 | 인덱스의 원리와 단점은? / 트랜잭션 ACID 와 격리 수준 | index, transaction-acid |
| 컴퓨터구조 | 캐시는 왜 빠른가(지역성)? / 32비트와 64비트의 차이 | memory-hierarchy, cpu |

공부법은 단순하다. 과목당 질문 15~20개를 뽑고, 각 질문을 **정의 → 왜 → 장단점** 1분 답으로 만들고, 카드의 related 를 따라가며 꼬리 질문을 대비한다. 시점이 중요한데, 3학년에 그 과목 수업을 듣는 학기에 바로 면접 질문 형태로 정리해야 한다 — 기말 끝나고 한 학기 지나면 다시 처음부터다.

여섯 개를 다 깊게 하는 건 불가능하다. **넓게 6 + 깊게 1** 이 현실적인 목표고, 깊게 팔 하나는 희망 직무가 정한다.

| 직무 | 더 깊게 | 실무 연결 질문 |
| --- | --- | --- |
| 백엔드 | DB·네트워크·OS | 커넥션 풀 크기는 어떻게 정하나? 격리 수준을 낮추면 뭐가 생기나? |
| 프론트 | 네트워크·자료구조 | 브라우저가 HTML 을 받아 화면에 그리기까지? |
| 인프라 | OS·네트워크 | 프로세스가 좀비가 되는 경우는? 서브넷을 왜 나누나? |
| AI·데이터 | 알고리즘·DB + 선형대수·확률 | 이 전처리의 시간복잡도는? |

면접관이 "OS 를 왜 알아야 하나요?" 라고 물으면 "스레드 풀 크기와 컨텍스트 스위칭 비용을 모르면 서버 설정을 감으로 하게 된다" 처럼 **실무와 연결해서** 답한다. 그게 여섯 과목을 왜 공통으로 묻는지에 대한 답이기도 하다.

## 헷갈리기 쉬운 것

- **코딩 테스트의 알고리즘**은 문제를 푸는 것, **면접의 알고리즘**은 "왜 그 복잡도인가" 를 설명하는 것. 둘 다 Big-O 가 뿌리다.
- **소프트웨어 공학·컴파일러·이산수학**도 나오긴 하지만 빈도가 낮다. 여섯 개를 끝낸 뒤에.
- **정처기 과목**과 겹치지만 자격증은 객관식 고르기, 면접은 "설명해 보세요" 다. 깊이가 다르다.
