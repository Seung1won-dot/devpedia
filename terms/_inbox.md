# Inbox — 모르는 용어를 만나면 한 줄 추가 (0초 규칙)

빌드 대상이 아니다(`_` 로 시작하는 파일은 무시). 주 1회 여기서 10개를 골라 카드로 옮긴다.
카드 만들기: `npm run new -- <category> <id> "<표시 이름>"` → 4필드 작성 → `npm run validate`.

형식: `- 용어 — 어디서 봤나 / 한 줄 메모` (카테고리 추정은 선택)
