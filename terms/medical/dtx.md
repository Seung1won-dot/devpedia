## 한 줄 정의

의사가 처방하고 **치료 효과를 임상시험으로 입증해 허가받은** 소프트웨어(앱).

## 비유

**약 대신 처방전에 적히는 앱**. 약국에서 알약을 받는 대신 앱을 깔고 처방 코드를 넣으며, 매일 쓰지 않으면 약을 안 먹은 것과 같다.

## 예시

```text
처방 → 앱 설치 → 처방 코드 입력 → 6~8주 프로그램(수면 일기, 인지행동치료 세션) → 사용 로그가 의사 대시보드로
```

```json
{ "subject": "S-014", "ts": "2026-10-02T22:10:00+09:00",
  "event": "session_complete", "module": "cbt-i/week3/sleep-restriction",
  "sleep_diary": { "in_bed": "23:40", "wake": "06:30", "efficiency": 0.82 } }
```

국내 1호는 불면증 인지행동치료 앱(2023년 식약처 허가)이고, 이후 불면·호흡재활·우울 등에서 허가가 이어졌다 [확인 필요]. 치료 수단이 "사용" 그 자체라 사용 로그가 곧 복약 기록이고, 백엔드는 이 이벤트를 환자별 시계열로 쌓아 순응도·효과 지표를 계산한다. 트레이드오프: 약보다 부작용이 적고 복제 비용이 0 에 가깝지만, 효능을 임상시험으로 증명해야 하고 앱 업데이트마다 변경 관리가 붙어 일반 앱처럼 매주 배포할 수 없다. 환자가 앱을 안 켜면 치료가 안 되므로 UX 와 알림 설계가 임상 결과에 직접 영향을 준다.

## 헷갈리기 쉬운 것

- **건강관리 앱**(명상·걸음 수)은 질병 치료를 표방하지 않아 허가가 없고 누구나 받는다. DTx 는 특정 질환의 치료 효과를 입증했고 처방이 있어야 쓴다.
- **CDSS/의료 AI** 는 의사를 돕는 소프트웨어, DTx 는 환자가 직접 쓰는 치료 소프트웨어. 사용자가 다르다.
- 식약처 공식 명칭은 **디지털 치료기기**다. 기사·업계는 "디지털 치료제" 라고 부르지만, 약(제)이 아니라 의료기기(기기)로 분류된다.
