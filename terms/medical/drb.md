## 한 줄 정의

병원이 **가명처리된 환자 데이터를 연구에 써도 되는지** 반출 전에 심사하는 위원회.

## 비유

공항 **세관 검사대**. 비행기 표(IRB 승인)가 있어도 짐 안에 반출 금지품(식별 정보)이 없는지, 신고한 양만큼만 가져가는지 따로 확인받아야 나갈 수 있다.

## 예시

```text
IRB 승인 → DRB 신청서(연구 목적, 필요 변수 목록, 가명처리 방법, 보관 장소·기간, 접근자 명단)
        → 심의: 변수가 목적에 비해 과하지 않은가 / 재식별 위험은 / 반출할지 원내 분석실에서만 쓸지
        → 조건부 승인(예: 생년월일 → 연령대, 희귀질환 코드 제외) → 추출·반출 → 종료 후 폐기 확인
```

2020년 개인정보보호법 개정으로 가명정보를 과학적 연구에 동의 없이 쓸 수 있게 되면서, 보건복지부 가이드라인이 의료기관에 가명처리 적정성을 심의하는 "데이터 심의위원회" 를 두도록 했고 [확인 필요], 병원들이 이를 DRB 로 운영한다. 연구실 신입이 겪는 현실: IRB 승인이 났는데 데이터가 안 오는 이유가 대개 DRB 대기이고, 신청서의 "필요 변수" 에 "일단 전부" 라고 적으면 반려된다 — 변수마다 왜 필요한지 적어야 한다. 반출 대신 병원 안 폐쇄망 분석실에서만 쓰라는 조건이 붙기도 한다.

## 헷갈리기 쉬운 것

- **IRB** 는 연구가 **윤리적으로 괜찮은지**(대상자 보호)를 보고, **DRB** 는 데이터 처리가 **법·가이드라인에 맞는지**(가명처리 적정성, 반출 범위)를 본다. 둘 다 통과해야 데이터를 받는다.
- **가명정보 결합 전문기관** 은 서로 다른 기관의 가명정보를 합칠 때 거치는 국가 지정 기관으로, 병원 내부 위원회인 DRB 와는 다르다 [확인 필요].
- 병원마다 **이름이 다르다**: 데이터심의위원회, 데이터활용심의위원회, 빅데이터심의위원회 등. 역할은 비슷하다.
