## 한 줄 정의

조직의 **정보보호·개인정보보호 관리체계**가 기준에 맞는지 KISA 등이 심사해 주는 국내 인증.

## 비유

음식점의 **위생 등급 인증**. 주방이 깨끗한지 한 번 보는 게 아니라 청소 규칙·점검표·담당자가 있고 실제로 돌아가는지를 보고, 등급을 받아도 매년 다시 점검받는다.

## 예시

```text
ISMS-P 인증기준 (항목 번호 [확인 필요])     연구실 서버에서 실제로 요구되는 것
2.5 인증 및 권한관리                       개인 계정 + SSH 키, 공용 계정 금지, 퇴사자 계정 즉시 삭제
2.6 접근통제                               연구망/병원망 분리, 허용 IP 만 SSH, sudo 최소 권한
2.7 암호화 적용                            디스크 암호화(LUKS), 전송은 TLS/SSH, 환자키는 해시+솔트
2.9 시스템 및 서비스 운영관리               접속·명령 로그를 변조 못 하게 별도 서버에 보관
3.x 개인정보 처리단계별 요구사항             수집 근거(IRB·가명처리), 보유기간 지나면 파기하고 기록
```

병원이 인증 의무 대상(상급종합병원 등 [확인 필요])이면 범위 안의 모든 시스템이 심사 대상이라, 연구실 GPU 서버에도 "누가 언제 접속했고 어떤 데이터를 반출했는지" 증빙이 요구된다. 인증은 3년 유효에 매년 사후심사이고, 기준은 관리체계·보호대책·개인정보 처리 세 영역 100여 개 항목이다 [확인 필요]. 트레이드오프: 연구 서버를 인증 범위에 넣으면 pip install 하나에도 절차가 붙어 느려지지만 병원 데이터를 합법적으로 다룰 수 있고, 범위 밖에 두면 자유롭지만 그 서버엔 환자 데이터를 둘 수 없다. 그래서 폐쇄망 연구 구역만 따로 엄격하게 묶는 설계가 보통이다.

## 헷갈리기 쉬운 것

- **ISMS** 는 정보보호만, **ISMS-P** 는 개인정보 처리 항목까지 더한 것. 환자 정보를 다루는 병원은 P 가 붙은 쪽이 의미 있다.
- **ISO/IEC 27001** 은 국제 민간 인증, ISMS-P 는 한국 법(정보통신망법·개인정보보호법)에 근거한 인증으로 일정 규모 이상은 의무다 [확인 필요]. 글로벌 고객에겐 27001, 국내 규제엔 ISMS-P.
- **개인정보보호법 준수**는 모든 조직의 의무이고, ISMS-P 는 그걸 체계로 갖췄음을 제3자가 확인해 주는 것.
- **정보보안기사**는 사람이 따는 자격증, ISMS-P 는 조직이 받는 인증.
