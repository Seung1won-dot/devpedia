## 한 줄 정의

사용자가 목표를 이루기까지 거치는 **화면과 행동의 순서**를 그린 지도.

## 비유

길 찾기 앱의 **경로 안내**. 출발지와 도착지 사이에 어디서 꺾는지, 어디서 막히면 돌아가는지가 다 보인다.

## 예시

```text
[홈] → 검색창에 "LXC" 입력 → [검색 결과]
   ├─ 결과 있음 → 카드 클릭 → [카드 상세] → related 칩으로 다음 카드
   └─ 결과 없음 → [빈 상태] → "비슷한 용어" 제안 / 카테고리로 이동
```

개발자에게 사용자 흐름은 **화면 목록과 분기 조건 목록**이다. 위 그림에서 "결과 없음" 갈래가 없었다면 빈 상태 화면이 시안에서 빠졌을 것이다. 저니 맵은 여기에 단계별 감정(답답함·안심)과 접점(이메일·앱 알림)까지 얹은 더 넓은 그림이다.

## 헷갈리기 쉬운 것

- **사용자 흐름 vs 저니 맵**: 흐름은 한 기능 안의 화면 순서, 저니 맵은 제품 밖까지 포함한 경험 전체와 감정이다.
- **시퀀스 다이어그램**은 시스템 구성 요소 사이의 메시지 순서, 사용자 흐름은 사람이 보는 화면의 순서다. 같은 기능을 서로 다른 눈으로 그린다.
