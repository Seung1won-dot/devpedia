### 첫 화면을 가볍게 만든 것

- 검색 인덱스(MiniSearch)는 첫 검색 때 만든다. 615장을 첫 렌더 전에 인덱싱하던 비용이 빠졌다.
- 본문 JSON(2.3MB, gzip 577KB)은 용어 페이지·미리보기·검색에서 필요할 때, 아니면 한가할 때 받는다.
- Pretendard 조각은 첫 데이터 화면을 그린 뒤 유휴 시간에 붙인다. 한 페이지에 20개 안팎(약 500KB)이라 첫 화면과 대역폭을 다투면 모바일 성능이 75 안팎으로 떨어졌다.
- 그 전까지 쓰는 맑은 고딕을 Pretendard 글자 폭에 맞췄다(`size-adjust: 87.2%`). 폰트가 바뀌어도 줄바꿈이 거의 같아 CLS 가 0.31 → 0.005.
- `index.html` 에 정적 헤더 셸, `main` 최소 높이로 푸터 밀림 제거.

### 남은 것: 모바일 용어 페이지 81

용어 페이지의 비유·예시는 본문 JSON 하나(전체 615장, gzip 577KB)가 와야 그려진다. 모바일 저속망 시뮬레이션에서 이 한 파일이 LCP 5.0s 를 만든다.
고치려면 `scripts/build-terms.ts` 가 본문을 분야별(또는 카드별) 파일로 나눠 내보내야 한다. 이번 작업은 빌드 스크립트를 건드리지 않는 조건이라 그대로 두었다.
재방문은 서비스 워커가 본문을 캐시해 바로 열린다.
