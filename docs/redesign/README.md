리디자인 전 기록(238장 기준): 데스크톱 100, 모바일 89(gzip 없는 서버).

### 첫 화면을 가볍게 만든 것

- 검색 인덱스(MiniSearch)는 첫 검색 때 만든다. 615장을 첫 렌더 전에 인덱싱하던 비용이 빠졌다.
- 본문 JSON(2.3MB, gzip 577KB)은 용어 페이지·미리보기·검색에서 필요할 때, 아니면 한가할 때 받는다.
- Pretendard 조각은 첫 데이터 화면을 그린 뒤 유휴 시간에 붙인다. 한 페이지에 20개 안팎(약 500KB)이라 첫 화면과 대역폭을 다투면 모바일 성능이 75 안팎으로 떨어졌다.
- 그 전까지 쓰는 맑은 고딕을 Pretendard 글자 폭에 맞췄다(`size-adjust: 87.2%`). 폰트가 바뀌어도 줄바꿈이 거의 같아 CLS 가 0.31 → 0.005.
- `index.html` 에 정적 헤더 셸, `main` 최소 높이로 푸터 밀림 제거.

### 남은 것: 모바일 용어 페이지 81

용어 페이지의 비유·예시는 본문 JSON 하나(전체 615장, gzip 577KB)가 와야 그려진다. 모바일 저속망 시뮬레이션에서 이 한 파일이 LCP 5.0s 를 만든다.
고치려면 `scripts/build-terms.ts` 가 본문을 분야별(또는 카드별) 파일로 나눠 내보내야 한다. 이번 작업은 빌드 스크립트를 건드리지 않는 조건이라 그대로 두었다.
재방문은 서비스 워커가 본문을 캐시해 바로 열린다.

## 모션 규칙 (2026-11)

움직임은 핵심 요소에만 둔다. 많이 움직일수록 어수선하고 "AI가 만든 것 같은" 화면이 된다. 타이포·간격·위계가 먼저고, 모션은 그걸 대신하지 않는다.

| 도구 | 어디에 | 무엇을 |
| :-- | :-- | :-- |
| **anime.js v4** (`animejs`) | 홈 첫 화면만 (`src/lib/intro.ts`) | 제목 글자가 하나씩 떠오르고(`stagger(34)`), 이어서 라벨·설명·검색창·숫자가 차례로. 세션당 한 번, 0.7초 안에 스크립트가 안 오면 그냥 보인다. 별도 조각(gzip 15KB)으로 홈에 들어올 때만 받는다 |
| **Motion** (`motion/react`, 무료 기능만) | 화면 전환 · 섹션 등장 · 분야 타일 · 탭 밑줄 · 분야 메뉴 · 별표 · 차트 | 화면 전환은 투명도 + 6px 상승 240ms. 섹션은 화면에 들어올 때 한 번(`whileInView`, once). 분야 타일은 그룹마다 40ms 간격. 난이도 탭의 오렌지 밑줄은 스프링으로 미끄러진다. 별표는 켤 때만 한 번 튄다. `LazyMotion` + `m` 으로 기능 묶음(gzip 18KB)을 따로 받는다 |
| **차트** (`src/components/BarChart.tsx`, Motion + SVG) | 통계 화면 | 분야별(5개 그룹으로 묶음)·난이도·카드 종류 막대. 화면에 들어오면 막대가 차례로 자라고, 호버·포커스하면 그 막대만 오렌지로 남고 "N개 · 전체의 n%" 툴팁 |

- 공통값은 `src/lib/motion.ts` (곡선은 `--ease-out` 과 같은 `[0, 0, 0.2, 1]`, 스프링 2종).
- 하지 않는 것: 호버 때 크기·그림자 변화, 무한 반복, 12px 넘는 이동, 카드마다 다른 효과, 패럴랙스.
- **모션 축소**(`prefers-reduced-motion: reduce`): `<MotionConfig reducedMotion="user">` 가 이동·크기 애니메이션을 끄고(투명도만 남김), anime.js 인트로는 받지도 돌지도 않는다. CSS 전환은 기존 토큰(`--dur-*: 0ms`)과 전역 규칙으로 꺼진다.
- **차트 도구**: 처음엔 Bklit UI(shadcn 레지스트리) 차트를 쓰려 했으나, Bar Chart 하나가 Tailwind 클래스 · `cn()` · d3-scale · @number-flow/react 와 레지스트리 파일 20여 개를 요구했다. Tailwind 를 쓰지 않는 이 앱엔 과해서, 같은 역할(항목 비교 · 등장 애니메이션 · 호버 값)만 하는 작은 차트를 Motion + SVG 로 만들었다. 차트는 실제 데이터(빌드 통계)가 있는 통계 화면에만 쓴다.
